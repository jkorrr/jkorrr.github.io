# jkorr — a place for unfinished things

A single-page, writing-first personal site built with React, TypeScript, Vite, and Motion.

## Local development

```bash
npm install
npm run dev
```

Update homepage copy, social links, and curated essay entries in `src/content.ts`.

## Publishing

The GitHub Pages workflow builds and deploys the site whenever `main` is pushed to the `jkorrr.github.io` repository.
